**Already have RoN-Fix?** Nothing to do: this version downloads itself while you play and is used from your next start.

**New here?** Download **RoN-Fix-Setup.exe** below, close the game, double-click it and press **Install**.
If Windows shows "Windows protected your PC", click **More info**, then **Run anyway**.

**New in 0.14: built in the open**

- RoN-Fix's source code is now public under the MIT licence, together with the releases, at
  [soul-builds/RoN-Fix](https://github.com/soul-builds/RoN-Fix). This release was built by GitHub Actions
  straight from that code (see the link at the end), and anyone can rebuild it and get the same files.
- Every RoN-Fix file now shows its name and version in Windows: right-click the file, then Properties > Details.
- The fixes themselves are unchanged from 0.13. All five files are new builds, so the update replaces all of them.

**Smart App Control.** If your PC has Windows' Smart App Control switched on, Windows may refuse this version's
files. RoN-Fix then simply stays on the version you have, and Windows may show a "blocked" notice a few seconds
after the game starts. Nothing breaks; the notice is harmless.
