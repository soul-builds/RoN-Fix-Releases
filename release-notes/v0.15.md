**Already have RoN-Fix?** Nothing to do: this version downloads itself while you play and is used from your next start.

**New here?** Download **RoN-Fix-Setup.exe** below, close the game, double-click it and press **Install**.
If Windows shows "Windows protected your PC", click **More info**, then **Run anyway**.

**New in 0.15: friendlier with Windows' Smart App Control**

- **No more "Bad Image" error at start-up.** The fix for the crash on quit no longer replaces the game's
  dssl.dll; RoN-Fix now applies it to the game's own file while the game runs. Your original dssl.dll comes back
  by itself at the next start. On PCs with Smart App Control on, Windows sometimes refused RoN-Fix's replacement
  file and showed that error at every start.
- **Fewer Windows notices.** If Windows refuses a new RoN-Fix version, RoN-Fix tries it again only a week later,
  not at every game start.
- **The loader stays as it is.** The one file the game cannot start without is no longer rebuilt with every
  release, so Windows keeps the verdict it already gave it.
- **Smart App Control... button.** If Smart App Control is on, the RoN-Fix window (Start menu) shows a button that
  explains what it does and what your options are. RoN-Fix never changes that setting itself.
- **Safer install.** The setup asks Windows first whether it would load RoN-Fix's loader, and leaves the game
  untouched if not.
- RoN-Fix's log now notes whether Smart App Control is on. That shows how many players it affects.
